# Intuition

In a rotated sorted array, although the whole array is not sorted, **at least one half of the current search range is always sorted**.

We use `low`, `mid`, and `high` to identify which half is sorted.

Once we identify the sorted half, we check whether the **target lies within that sorted range**:

- If it does → search that half.
- If it doesn't → discard that half and search the other half.

This allows us to eliminate half of the remaining elements at every step, just like normal binary search.

# Approach

1. Initialize:
   - `low = 0`
   - `high = n - 1`

2. While `low <= high`:
   - Calculate `mid`.
   - If `nums[mid] == target`, return `mid`.

3. Determine which half is sorted:
   - If `nums[low] <= nums[mid]`, the **left half is sorted**.
   - Otherwise, the **right half is sorted**.

4. If the left half is sorted:
   - Check whether `target` lies between `nums[low]` and `nums[mid]`.
   - If yes, search left:
     `high = mid - 1`
   - Otherwise, search right:
     `low = mid + 1`

5. If the right half is sorted:
   - Check whether `target` lies between `nums[mid]` and `nums[high]`.
   - If yes, search right:
     `low = mid + 1`
   - Otherwise, search left:
     `high = mid - 1`

6. If the loop ends, the target doesn't exist:
   - Return `-1`

# Complexity
- Time complexity:
<!-- Add your time complexity here, e.g. $$O(n)$$ -->
O(logN)

- Space complexity:
<!-- Add your space complexity here, e.g. $$O(n)$$ -->
O(1)

# Code
```cpp []
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int low = 0;
        int high = nums.size() - 1;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (nums[mid] == target)
                return mid;
            else if (nums[low] <= nums[mid]) {
                if (target >= nums[low] && target <= nums[mid]) {
                    high = mid-1;
                } else {
                    low = mid + 1;
                }
            } else {
                if (target >= nums[mid] && target <= nums[high]) {
                    low = mid + 1;
                } else
                    high = mid-1;
            }
        }
        return -1;
    }

};
```
