# Car Fleet

**LeetCode:** 853
**Pattern:** Sorting + Greedy / Monotonic Behavior
**Difficulty:** Medium
**Importance:** ⭐⭐⭐⭐

---

## Problem

You are given:

* `target` → destination position.
* `position[i]` → current position of a car.
* `speed[i]` → speed of that car.

A car cannot overtake another car.

If a faster car behind catches a slower car ahead before reaching the target, they travel together and form a **fleet**.

Return the total number of fleets that reach the target.

### Example

```text
target = 12

position = [10, 8, 0, 5, 3]
speed    = [ 2, 4, 1, 1, 3]

Output = 3
```

---

## 🔹 Intuition (Institution)

The first step is to understand what a **fleet** means.

Consider:

```text
Ahead car → slow
Behind car → fast
```

If the faster car catches the slower car:

```text
Fast car catches slow car
        ↓
Cannot overtake
        ↓
They move together
        ↓
One fleet
```

Instead of calculating the exact point where two cars meet, calculate how long each car would take to reach the target if no other cars existed.

```text
time = (target - position) / speed
```

Now process cars from:

```text
Closest to target
        ↓
Farthest from target
```

Maintain the arrival time of the most recent fleet.

### Core condition

```text
currentTime > fleetTime
```

The current car cannot catch the fleet ahead.

```text
→ New fleet
```

Otherwise:

```text
currentTime <= fleetTime
```

The current car catches the fleet ahead before reaching the target.

```text
→ Joins the existing fleet
```

The fleet's arrival time remains the same because the slower fleet ahead determines when all cars in that fleet reach the target.

---

## 🔹 Approach

1. Pair every car's `position` with its time required to reach the target.

   ```text
   time = (target - position) / speed
   ```

2. Store the pairs in descending order of position.

   ```text
   closest to target → farthest from target
   ```

3. Initialize:

   ```text
   count = 0
   fleetTime = 0
   ```

4. Iterate through the cars.

5. For every car:

   If:

   ```text
   currentTime > fleetTime
   ```

   then:

   ```text
   count++
   fleetTime = currentTime
   ```

   because this car forms a new fleet.

6. Otherwise:

   ```text
   currentTime <= fleetTime
   ```

   the car catches the fleet ahead, so it joins that fleet.

   No changes are required.

7. Return `count`.

---

## 🔹 C++ Solution

```cpp
class Solution {
public:
    int carFleet(int target, vector<int>& position, vector<int>& speed) {
        map<int, double, greater<int>> mp;

        int count = 0;
        double fleetTime = 0;

        for (int i = 0; i < position.size(); i++) {
            double temp = target - position[i];
            mp[position[i]] = temp / speed[i];
        }

        double curr = 0;

        for (auto it : mp) {
            curr = it.second;

            if (curr > fleetTime) {
                count++;
                fleetTime = curr;
            }
        }

        return count;
    }
};
```

## 🔹 Dry Run

Suppose the cars, after sorting by position, have arrival times:

```text
3, 2, 4, 1
```

Process from left to right:

### `3`

No fleet ahead.

```text
New fleet
count = 1
fleetTime = 3
```

### `2`

```text
2 <= 3
```

The car catches the fleet ahead.

```text
Joins existing fleet
count = 1
fleetTime = 3
```

### `4`

```text
4 > 3
```

This car cannot catch the fleet ahead.

```text
New fleet
count = 2
fleetTime = 4
```

### `1`

```text
1 <= 4
```

It catches the fleet ahead.

```text
Joins existing fleet
count = 2
fleetTime = 4
```

### Final Answer

```text
2 fleets
```

## 🧠 Mistakes and Learning Process

### 1. Started thinking about the algorithm before understanding the problem

Initially, the meaning of a **car fleet** itself was unclear.

The improvement was:

```text
First understand the scenario
        ↓
Understand what each condition means
        ↓
Identify what needs to be calculated
        ↓
Then think about the pattern/data structure
```

### Important lesson

> **Do not force a pattern before understanding what the problem is actually asking.**

---

### 2. Initially thought equal arrival times were required

The initial thought was:

```text
Same arrival time
→ Fleet
```

But that is incomplete.

The actual condition is:

```text
currentTime <= fleetTime
```

The car behind can originally have a smaller arrival time, meaning it would reach the target earlier and therefore catches the slower fleet ahead.

Because overtaking is not allowed:

```text
It catches the fleet
→ Cannot pass
→ Joins the fleet
```

---

### 3. Realized that a fleet can contain multiple cars

A fleet is not limited to two cars.

Example:

```text
Times: 3, 2, 1
```

```text
3 → Creates fleet
2 → Joins
1 → Joins
```

Final:

```text
1 fleet containing 3 cars
```

---

### 4. Pattern understanding

Although this problem can be introduced alongside **Monotonic Stack**, the final solution does not require an explicit stack.

The solution can be simplified to:

```text
Sort by position
        ↓
Process from closest → farthest
        ↓
Maintain fleetTime
        ↓
Count whenever currentTime > fleetTime
```

### Core mental model

> **If a car behind would arrive earlier than or at the same time as the fleet ahead, it catches that fleet and becomes part of it. Otherwise, it creates a new fleet.**
